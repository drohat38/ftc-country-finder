# Feed The Country Event Finder

Finder page for Tango Charities' Feed The Country (Saturday, September 19, 2026). Reads a Google Sheet, draws a clickable US map, and lists every city with a Register button to its Eventbrite page. Embedded in the Wix page https://www.tangocharities.org/country by URL.

Start with `docs/HANDOFF.md`. See CLAUDE.md for the repo map and rules.
